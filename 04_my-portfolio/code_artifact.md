# ポートフォリオサイト 要件・設計仕様書

## 1. 概要・プロジェクトコンセプト

* **サイト名**: （任意設定：ポートフォリオタイトル）
* **テーマ**: 女体の美・身体のライン・光と陰影にフォーカスしたポートレート写真ポートフォリオ
* **表現の範囲**: アート性・造形美を追求した表現（目安として **R-15 程度** の表現範囲とし、純粋な芸術作品・写真作品として構築する）
* **インフラ / ホスティング**: **Cloudflare Pages**（Git連携による自動デプロイ、高速な全局面配信、独自ドメイン運用）

## 2. サイト構造（アーキテクチャ）

全体の構成は、トップページを案内板（エントランス）とし、ロケーションやトーンごとに分かれた2つのギャラリーページへ遷移する**2階層のツリー構造**を採用する。

```text
/ (TOP: エントランスページ)
│
├── /studio/ (Studio Gallery: 室内・ライティング・造形美)
└── /nature/ (Nature Gallery: 自然ロケーション・屋外・対比美)
```

### 2.1 各ページの役割
1. **トップページ (`/index.html`)**
   * ミニマルなブランド感・アーティスト感を演出するエントランス。
   * 画面を左右（または上下）に分けるか、直感的なナビゲーションで `Studio` と `Nature` の2つの作品集への選択肢を提示する。
2. **Studio ギャラリー (`/studio/index.html`)**
   * 屋内・スタジオにてコントロールされた光、陰影、骨格や肉体のライン、モノクローム中心の彫刻的表現に特化した作品群を掲載。
3. **Nature ギャラリー (`/nature/index.html`)**
   * 川、渓谷、木漏れ日など、自然ロケーションにおける肌の質感、光と水、自然物との対比・力強さに特化した作品群を掲載。

## 3. デザイン & ビジュアル仕様

* **カラーパレット**
  * メイン背景色: `#000000`（純黒）または `#0a0a0a`（深みのあるダークグレー）
  * テキスト色: `#e0e0e0`（抑えめのライトグレー、細身のフォントを使用）
* **サムネイル & ギャラリー表示**
  * **正方形（1:1）グリッド**: 一覧画面ではアスペクト比を揃え、整然とした「ギャラリー感」を出す。
  * **額装風エフェクト（ドロップシャドウ）**: 暗い背景の上で写真が際立つよう、微細なグレーのグロー効果（`box-shadow: 0 4px 20px rgba(255,255,255,0.05)` など）や、1pxの極薄ボーダーを適用。
  * **カラー / モノクロの混在**: ページ全体のトーン・マナーを統一しつつ、並び順（シークエンス）に配慮して交互・効果的に配置する。
* **フルスクリーンモーダル（拡大表示）**
  * サムネイル画像をタップ/クリックすると、画面全体を暗転させてモーダルダイアログを表示。
  * モーダル内では**切り抜きなしの100%原寸アスペクト比（縦長・横長）**で写真を全画面フィット表示。

## 4. レスポンシブ対応

画面サイズに応じてグリッドの列数およびレイアウト手法を切り替える。

* **スマートフォン表示（〜768px）**
  * **2列の正方形グリッド**
  * タッチ操作・親指での快適なスクロールを重視し、高密度かつ視認性の良い一覧性を確保。
* **デスクトップ PC表示（768px〜）**
  * **3〜4列のダイナミックグリッド（またはMasonry風レイアウト）**
  * 大画面での正方形タイルの窮屈さを解消するため、ホバーエフェクト（暗転・拡大）を取り入れつつ、写真のスケール感をダイナミックに強調する。

## 5. 技術仕様・セキュリティ・データ保護

1. **メタデータ（EXIF）の削除**
   * 撮影時の位置情報（GPS）、日時、環境データ等のプライバシー情報を保護するため、デプロイ前の画像出力（WebP / AVIF変換）段階ですべてのEXIFデータを完全自動消去する。
2. **画像の最適化**
   * サムネイル用（軽量・正方形トリミング）とモーダル拡大用（高解像度・原寸比率）の画像を分けて生成し、Lazy Loading（遅延読み込み）を実装して初期読み込み速度を最大化する。
3. **年齢認証・アクセス制御**
   * ギャラリー初回アクセス時に、表現範囲（R-15程度）への事前確認メッセージを表示し、同意保持用Cookie / localStorage を保存する。
4. **検索エンジン最適化（SEO / メタ情報）**
   * 適切なメタタグを宣言し、アート作品としての文脈を明記する。
   ```html
   <meta name="rating" content="R-15">
   <meta name="description" content="女体の造形美と光と影を追求したポートレート写真ポートリオ">
   ```
