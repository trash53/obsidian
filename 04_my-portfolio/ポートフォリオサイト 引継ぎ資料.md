# ポートフォリオサイト 引継ぎ資料

これまでの検討内容・決定事項・未決事項・次のアクションをまとめた資料です。新しい会話や作業者に渡すとき、この資料と仕様書（改訂版）を併せて共有してください。

## 1. プロジェクトの現状

- **段階**：仕様の確定まで完了。実装（コード作成）は未着手
- **制作者**：Webサイト制作は初めて。管理方法も含めて提案を受けながら進める
- **成果物**：仕様書（改訂版）は別ドキュメントとして作成済み
- **想定構成**：Astro + GitHub + Cloudflare Pages

## 2. サイトの目的と内容

- 身体のライン・光と陰影にフォーカスしたポートレート写真のポートフォリオ
- 構成：トップ（エントランス）／Studio／Nature／About／Contact／Privacy
- 全年齢が見て問題のない範囲の芸術写真として運用（成人向けコンテンツではない）

## 3. 決定事項

| 項目 | 決定内容 |
| --- | --- |
| 閲覧制限 | 設けない（年齢確認画面・Cookie保存なし） |
| レーティング | R-15表記と `rating` メタタグは廃止 |
| 許可表記 | モデルは全員成人で、撮影・掲載の許可を得ている旨をフッターと /about/ に記載 |
| 取り下げ・連絡 | お問い合わせフォームを用意（取り下げ依頼も兼ねる） |
| 作者紹介 | /about/ を設ける |
| 販売 | なし。依頼受付を始める場合に利用規約を追加 |
| 右クリック防止 | 実装する（右クリック・ドラッグ・長押し保存の抑止） |
| ウォーターマーク | 画像側に入れた状態で用意（拡大用画像にも入れる） |
| クロール対策 | robots.txt、noimageindex、X-Robots-Tag、CloudflareのAIボットブロックを併用。OGPのみ例外 |
| OGP画像 | 制作者が用意（/public/ogp/ に配置） |
| グリッド | 正方形タイルの上に原寸比率の画像を contain で配置（トリミングしない） |
| 余白色 | 暗めのグレー（案：#1c1c1c）で統一 |
| ロゴ・キャプション | ロゴなし、画像説明テキストなし（alt は `Studio 001` 形式で簡素に付与） |
| モーダル操作 | 矢印キーで前後移動、背景タップで閉じる。Escキー、スマホのスワイプ／前後ボタンも追加推奨 |
| 性能目標 | CLS 0.1以下 |
| 管理方法 | 画像をフォルダに入れて GitHub Desktop で Commit → Push すると自動公開。並び順はファイル名の番号順 |
| お問い合わせ方式 | 初回は Web3Forms または Formspree。スパム対策に Turnstile を後から追加可能 |

## 5. 注意点・リスク

- 右クリック防止はスクリーンショットや開発者ツールでの取得を防げません。実質的な保護はウォーターマークが担います。
- `robots.txt` はお願いベースです。複数の対策を併用しています。
- OGP画像はSNSのクローラーが取得するため、作品画像とは別フォルダに置き、クロール対策から除外します。
- 公開後に、実際の画像でEXIF（GPS・日時）が残っていないことを確認してください。
- 同意書・身分確認の記録はサイトに載せず、手元で保管します。
- 最初に画面に出る数枚は `loading="eager"` にし、それ以降は遅延読み込みにします。

## 6. 次のアクション

1. 未決事項（サイト名・ドメイン・フォーム）を決める
2. Node.js、VS Code、GitHub Desktop、GitHubとCloudflareのアカウントを用意する
3. Astroプロジェクトを作成し、ローカルで表示確認する（`npm create astro@latest`）
4. 共通レイアウト、トップ、ギャラリー（グリッド＋モーダル）を実装する
5. About、Contact、Privacy ページとフッターの許可表記を実装する
6. 保護・クロール対策ファイル（robots.txt、\_headers、メタタグ、右クリック防止）を設置する
7. ウォーターマーク入り画像とOGP画像を配置し、GitHubへプッシュ、Cloudflare Pagesで公開する
8. 公開前チェックリストで確認する（仕様書の第11章）
