# ポートフォリオサイト 要件・設計仕様書（改訂版）

決定事項を反映した改訂版です。Astro + GitHub + Cloudflare Pages での初回制作を想定しています。

## 1. 概要

- **サイト名**：（任意設定）
- **テーマ**：身体のライン・光と陰影にフォーカスしたポートレート写真ポートフォリオ
- **掲載基準**：全年齢が閲覧して問題のない範囲の芸術写真（成人向けコンテンツではない）
- **閲覧制限**：なし（年齢確認画面・Cookie保存は設けない）
- **販売**：なし（将来、依頼を受ける場合は利用規約を追加）
- **ホスティング**：Cloudflare Pages（GitHub連携による自動デプロイ）

> 公開前に、Cloudflareの利用規約で許容される表現範囲を確認してください。

## 3. デザイン仕様

- **背景色**：`#0a0a0a`
- **文字色**：`#e0e0e0`（細身のフォント。最初はシステムフォントで開始）
- **タイル（余白）色**：`#1c1c1c`（暗めのグレーで全作品統一）
- **ロゴ**：付けない。ウォーターマークは画像側に用意済み
- **キャプション・説明文**：なし

### グリッド表現

正方形にトリミングせず、正方形のタイルの上に原寸比率の画像を `contain` で中央配置します。

```css
.grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr); /* スマホ */
  gap: 8px;
}
@media (min-width: 768px) {
  .grid { grid-template-columns: repeat(3, 1fr); gap: 16px; }
}
@media (min-width: 1200px) {
  .grid { grid-template-columns: repeat(4, 1fr); }
}
.tile {
  aspect-ratio: 1 / 1;
  background: #1c1c1c;
  display: grid;
  place-items: center;
  border: 1px solid rgba(255,255,255,0.06);
  box-shadow: 0 4px 20px rgba(255,255,255,0.05);
  overflow: hidden;
}
.tile img {
  max-width: 100%;
  max-height: 100%;
  object-fit: contain;
  transition: transform .4s, opacity .4s;
}
@media (hover: hover) {
  .tile:hover img { transform: scale(1.04); opacity: .85; }
}
```

デスクトップも均等な正方形グリッドです（Masonry風にはしません）。

## 4. モーダル（拡大表示）

- タイルのタップ／クリックで全画面を暗転し、**切り抜きなしの原寸比率**で画像を画面内にフィット表示します。
- 閉じる：**背景タップ**、**Escキー**
- 前後移動：**矢印キー（← →）**、スマホは**左右スワイプ**または画面上の前へ／次へボタン
- 開いている間は背面のスクロールを止め、`scrollbar-gutter: stable` でレイアウトのズレを防ぎます。
- 閉じたときは、開く前にフォーカスしていたタイルへフォーカスを戻します。

## 5. 画像仕様

| 用途 | 長辺 | 形式 | 備考 |
| --- | --- | --- | --- |
| サムネイル | 600px前後 | WebP | 比率維持、`loading="lazy"` |
| モーダル用 | 2000px前後 | WebP | ウォーターマーク入り |
| OGP | 1200×630 | JPG | 用意済みのものを `/public/ogp/` に配置 |

- 元画像にはウォーターマークを入れた状態で `src/images/` に置きます。
- EXIFはAstro（sharp）の変換時に削除されます。公開後に実画像で確認してください。
- `alt` は簡素に `Studio 001` のように付けます（`alt=""` にはしません）。
- 全画像に `width`／`height` を付けます（Astroの `<Image>` が自動付与）。

## 6. 保護・クロール対策

### 右クリック・保存の抑止

```js
document.addEventListener('contextmenu', (e) => {
  if (e.target.closest('.tile, .modal')) e.preventDefault();
});
document.addEventListener('dragstart', (e) => {
  if (e.target.tagName === 'IMG') e.preventDefault();
});
```

```css
img { -webkit-touch-callout: none; user-select: none; -webkit-user-drag: none; }
```

スクリーンショットや開発者ツールでの取得は防げません。実質的な保護はウォーターマークが担います。

### クロール防止

`public/robots.txt`

```text
User-agent: *
Disallow: /_astro/
Allow: /ogp/
```

`public/_headers`（OGPだけヘッダーを外します）

```text
/*
  X-Robots-Tag: noimageindex
/ogp/*
  ! X-Robots-Tag
```

- 各ページの `<head>` に `<meta name="robots" content="noimageindex">` を入れます。
- CloudflareダッシュボードのAIボットブロック機能を有効にします。
- `robots.txt` はお願いベースのため、上記を併用します。

### メタ情報

```html
<meta name="description" content="光と影、身体のラインを追求したポートレート写真ポートフォリオ">
<meta property="og:image" content="https://（ドメイン）/ogp/ogp.jpg">
```

`rating` メタタグは使用しません。

## 7. 性能目標

- **CLS 0.1以下**：タイルが `aspect-ratio: 1/1` で先に確保され、画像に `width`／`height` が付くため、ほぼ0になる見込みです。
- 画面外の画像は遅延読み込みにします。最初に見える数枚は `loading="eager"` にします。
- 公開後、PageSpeed Insights でスマホ表示を計測して確認します。

## 8. お問い合わせフォーム

- 初回は **Web3Forms または Formspree**（HTMLに数行追加、メール受信）を使います。
- 項目：お名前、メールアドレス、種別（ご連絡／掲載取り下げ依頼）、本文
- スパム対策として、後から Cloudflare Turnstile（無料）を追加できます。
- フォーム利用に合わせ、`/privacy/` に取得する情報（メールアドレス等）と利用目的、外部サービスを使うことを記載します。

## 9. プライバシー・アクセス解析

- 年齢確認を行わないため、Cookie／localStorageは使用しません。
- アクセス解析が必要なら Cloudflare Web Analytics（Cookieなし）を使います。

### 初期セットアップ手順

1. Node.js（LTS）、VS Code、GitHub Desktop をインストールします。
2. ターミナルで次を実行します。

```bash
npm create astro@latest my-portfolio
cd my-portfolio
npm run dev
```

質問には「Empty」テンプレート、TypeScriptは「Relaxed」、Git初期化は「No」を選べば十分です。 3. ブラウザで `http://localhost:4321` を開き、表示を確認しながら作業します。 4. 上記のフォルダ構成に合わせてファイルを作ります（この作業はClaudeに依頼できます）。 5. GitHub Desktop で「Add local repository」から `my-portfolio` を追加し、GitHubに公開（Private可）します。 6. Cloudflareダッシュボードの **Workers & Pages** から Pages プロジェクトを作成し、GitHubリポジトリを接続します。

- ビルドコマンド：`npm run build`
- 出力ディレクトリ：`dist`

7. 公開URLで表示、モーダル、フォーム送信を確認します。
8. 独自ドメインを使う場合は、Pagesの「Custom domains」から設定します。

### ギャラリーの実装方針

```astro
---
import { Image } from 'astro:assets';
const files = import.meta.glob('/src/images/studio/*.{jpg,jpeg,png}', { eager: true });
const images = Object.entries(files)
  .sort(([a], [b]) => a.localeCompare(b))
  .map(([, m]) => m.default);
---
<div class="grid">
  {images.map((img, i) => (
    <button class="tile" data-index={i}>
      <Image src={img} width={600} format="webp"
             alt={`Studio ${String(i + 1).padStart(3, '0')}`}
             loading={i < 4 ? 'eager' : 'lazy'} />
    </button>
  ))}
</div>
```

- ファイル名の数字順で並ぶため、一覧ファイルは不要です。
- モーダル用の大きな画像は、ビルド時に `getImage()` で生成し、`data-` 属性にURLを持たせて表示時に読み込みます。

### 画像追加の流れ

1. ウォーターマーク入りの画像を `src/images/studio/` または `nature/` に、連番のファイル名で入れます。
2. GitHub Desktop で「Commit」→「Push」。
3. 数分で自動的に公開されます。

並び順を変えたいときは、ファイル名の番号を変更します。
