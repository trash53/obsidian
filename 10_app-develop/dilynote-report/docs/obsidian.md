# Obsidian 週報自動生成スクリプト システム仕様書

## 1. 概要
本システムは、Obsidian内の過去1週間分のデイリーノート（Markdownファイル）を読み込み、Google Gemini APIを活用して週報を自動生成し、Obsidian内の指定フォルダへ保存するとともに、Windowsのデスクトップ通知を出力する全自動ツールである。

---

## 2. システム構成・動作環境
- **開発言語:** Python 3.10+
- **使用SDK / ライブラリ:**
  - API制御: `google-genai` (最新公式SDK)
  - デスクトップ通知: `plyer`
  - パッケージング: `pyinstaller`
- **対象環境:** Windows 10 / 11 (64bit)
- **連携アプリ:** Obsidian (ローカルVault)

---

## 3. 機能要件

### 3.1 デイリーノートの読み込み
- 実行日を起点として、過去7日分のデイリーノート（例: `YYYY-MM-DD.md`）をVault内から読み込む。
- 該当日にファイルが存在しない場合はスキップし、存在するファイルのみを結合する。
- 7日間すべてノートが存在しない場合は処理を中断し、通知を出力する。

### 3.2 要約および補完処理 (Gemini API)
- **使用モデル:** `gemini-2.5-flash`
- **周辺情報の補完:**
  - プロンプト内にシステムコンテキスト（開発文脈、使用技術等）を埋め込み。
  - `tools=[{"google_search": {}}]` を有効化し、デイリーノート内の技術用語や外部ニュース等の背景情報を検索・補完。
- **要約フォーマット:** Markdown形式で以下の構成を出力。
  - `# 週間振り返り (YYYY-Wxx週)`
  - `## 今週の主な成果・ハイライト`
  - `## 進行中のプロジェクト・進捗`
  - `## 課題・反省点`
  - `## 来週のフォーカス`

### 3.3 Markdownファイルの保存
- 生成された週報テキストを、Obsidian内の指定フォルダ（例: `Weekly/`）にMarkdown形式で保存する。
- **ファイル名規則:** `YYYY-Wxx.md` (例: `2026-W44.md`)

### 3.4 Windowsデスクトップ通知
- 保存成功時、Windowsのデスクトップ右下にトースト通知を表示する。
  - **タイトル:** 週報を生成しました
  - **メッセージ:** Obsidianに保存完了: YYYY-Wxx.md
- エラー発生時にも対応するエラー通知を出力する。

---

## 4. ビルドおよび運用仕様

### 4.1 単体実行ファイル (.exe) 化
PyInstallerを使用して、Python未インストール環境でも動作する単一の実行可能ファイルへビルドする。
```bash
pyinstaller --onefile --noconsole obsidian_weekly_summary.py
```
*※ `--noconsole` オプションにより、バックグラウンド実行時のコマンドプロンプト表示を抑制する。*

### 4.2 自動化 (タスクスケジューラ登録)
- Windows タスクスケジューラを用いて定期実行する。
  - **トリガー:** 毎週日曜日 20:00 (推奨)
  - **操作:** `obsidian_weekly_summary.exe` の実行
  - **作業フォルダ(開始位置):** exeファイルおよび `.env` が配置されているフォルダを指定。
