# 究極の「触らない」デスクインテリア：2カラム・アンビエントダッシュボード システム仕様書

## 1. 概要 (Overview)
本システムは、旧型タブレット（Fire 7 9th Gen等）を「手動操作不要の受動的なアンビエント・ディスプレイ」として活用するための、シングルページWebアプリケーション（PWA対応）です。
PCやスマホのような操作性・タスク管理機能を削ぎ落とし、デスクの隅に置いて日常のコンテキスト（時間、部屋の空気感、外の天候）をスタイリッシュに可視化することを目的とします。

---

## 2. コアコンセプト (Core Concepts)
* **Zero Interaction（完全無干渉）**: 入力・タップ操作を前提とせず、起動したまま常時表示。
* **Deterministic Daily Theme（決定論的日替わり配色）**: 日付（`YYYY-MM-DD`）をシード値としてカラーパレットを自動計算。外部APIに依存せず、毎日0時に画面全体のアクセントカラーが自動変更される。
* **Apple-Inspired Aesthetic**: ダークモードベース、SF風の極細フォント、ほのかなネオン発光エフェクト（Glow Effect）による高いデザイン性。

---

## 3. システム構成 (System Architecture)

### 3.1 技術スタック
* **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Graphics Rendering**: HTML5 Canvas API (`requestAnimationFrame` による滑らかなアニメーション)
* **External APIs**: 
  * SwitchBot Local API / Cloud API (温湿度取得用)
* **Hosting**: GitHub Pages (HTTPS配信)

### 3.2 画面レイアウト (2カラム構成)
画面全体を左右50%ずつのレスポンシブな2カラムに分割。

```
+-----------------------------------+-----------------------------------+
|                                   |  ROOM & WEATHER                   |
|                                   |  -------------------------------  |
|                                   |  TEMPERATURE                      |
|                                   |  24.2 °C   [===============>   ]  |
|         LEFT PANEL (50%)          |  -------------------------------  |
|                                   |  HUMIDITY                         |
|   - 超ミニマル同心円クロック      |  48 %      [===========>       ]  |
|   - 日替わりカラーパレット        |  -------------------------------  |
|     スウォッチ表示 (HEXコード)    |  TODAY            TOMORROW        |
|                                   |  晴れ 21/12°C     曇り 19/11°C    |
|                                   |  -------------------------------  |
|                                   |  24h Temp Trend Graph             |
+-----------------------------------+-----------------------------------+
```

## 4. 機能仕様 (Functional Specifications)

### 4.1 左パネル: 超ミニマルクロック & 日替わりカラーパレット
1. **同心円アーク時計 (Concentric Arc Clock)**
   * **描画方法**: Canvas上に3本の同心円を描画。
   * **表現軸**:
     * **内側 (最細)**: 秒の経過（0〜60秒）
     * **中間**: 分の経過（0〜60分）
     * **外側 (最太)**: 時間の経過（0〜12時間）
   * **アニメーション**: ミリ秒補正によるなめらかな連続移動。
2. **決定論的パレット生成エンジン (Deterministic Palette Engine)**
   * 日付文字列（例: `2026-10-29`）から独自のハッシュ/シード値を生成。
   * HSL色空間を用いて、調和のとれた3色（秒・分・時用）＋アクセント1色のカラーコード（HEX）を割り出す。
3. **中央カラーチップUI (Swatches)**
   * 時計の中心部に、その日の配色テーマを示す3つの丸型カラーチップとHEXコード（例: `#FF5577`）をフロート表示。

### 4.2 右パネル: 空間・外気モニター (Metrics Stack)
1. **室温 (Temperature) カード**
   * **表示内容**: リアルタイム室温（℃）＋適正範囲を示すグラデーション・インジケーターバー。
   * **配色**: その日の秒リングカラーと自動連動。
2. **湿度 (Humidity) カード**
   * **表示内容**: リアルタイム湿度（%）＋インジケーターバー。
   * **配色**: その日の分リングカラーと自動連動。
3. **天気予報 (Weather Forecast) カード**
   * **データ取得元**: Open-Meteo API
   * **位置情報**: 山口県山陽小野田市（北緯 34.03, 東経 131.18）
   * **表示項目**: 
     * **今日 (TODAY)**: 天気テロップ（晴れ/曇り/雨等）、アイコン、最高/最低気温
     * **明日 (TOMORROW)**: 天気テロップ、アイコン、最高/最低気温
   * **更新頻度**: 3時間おきに自動再取得。エラー時はダミーデータへ自動フォールバック。
4. **24時間気温トレンド (Trend Graph)**
   * 下部にSVGを用いた緩やかな波形グラフを描画（時系列の温度推移を視覚化）。

## 5. 非機能要件 (Non-Functional Requirements)

* **パフォーマンス & パワー消費**:
  * 不要なDOM再描画を避け、軽量なCanvasとSVGのみを使用。古いFire 7でもCPU負荷率および発熱を最小限に抑える。
* **画面焼き付き防止 (Burn-in Prevention)**:
  * クロック描画およびプログレスバーが常に動き続けるため、静止画によるOLED/液晶の焼き付きを自然に防止。
* **画面サイズ追従性**:
  * Viewport単位 (`vw`, `vh`) と Canvasのリアルタイムリサイズイベントにより、アスペクト比 16:10 / 16:9 などの各種横長ディスプレイに自動ジャストフィット。
