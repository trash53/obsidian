# 在庫管理を極限までローフリクションに。「名もなき家事」を解き放つスマートライフスタイル管理システムの裏側

「冷蔵庫に何があったっけ？」「今日の夕飯、何作ろう…」「スーパーで何を買い足せばいいんだっけ？」

私を含め皆さんも悩ましいところではないでしょうか。ご飯が楽しみにとっては買い物も楽しい時間でしょうが、私のような日々の食事は栄養摂取が主目的な人にとっては面倒な家事です。

そこで今回は、このストレスを極限までゼロに近づけるために個人開発している「冷蔵庫在庫管理システム」**の設計思想と、UX（ユーザー体験）を突き詰めた結果たどり着いた泥臭くも強力な技術的アプローチをご紹介します。

---

## 🎯 開発の目的：「使われなくなること」が最大のリスク

家事効率化アプリや在庫管理ツールは世の中に溢れていますが、挫折する最大の理由は「入力が面倒くさいこと」です。

どれだけ高機能でも、使うために人間が頑張らなければいけないシステムは、数日後には放置されます。だからこそ、本システムの第一目標は「入力・運用負荷を極限までゼロに近づけること」に設定しました。

### コアコンセプト
**「レシートで入庫 ➔ 料理の際にキッチン前でスマホをポチポチして出庫 ➔ 在庫から導く提案と最短ルートでお買い物」**

人間の物理的な動線と行動パターンに完全に一致させた、ローフリクション（低摩擦）・アーキテクチャを目指しています。

 ※前提として、ここで冷蔵庫は倉庫として扱い、買い物して冷蔵庫に入れることを入庫、取り出すことを出庫と呼びます。
---

## 💡 突き詰めた6つの「泥臭い」設計方針

技術的に高度なことをする前に、ユーザー体験を損なわないための設計方針を徹底的に固めました。

1. **食材ベースを土台にする**
   - 料理名やレシピを入力させない。「豚肉」「たまねぎ」などの食材単位で管理する。
   - 自炊派のほとんどは名前のない料理を作っていることでしょう。なんかあった野菜と肉を炒めた料理とか。料理の際もいちいち分量を量ったりせず、目分量で入れているかと思います。
1. **レシピは使い捨ての仮説**
   - 買い物時の献立は確定した予定ではなく、システムからの提案をもとに買い物します。提案レシピを採用しなくても何の問題も起きない「緩さ」を持たせる。
1. **人間に聞かず、システムが推定する**
   - レシート表記寄せなどは、別名テーブルとAIで自動推定。確信度が低いものだけ人間に確認を求める。
1. **粗い粒度から始める**
   - 最初から「豚バラ150g」などと細かく管理せず、「豚肉」など大雑把な粒度からスタート。
5. **AIがコケてもユーザーの操作を止めない**
   - AIの応答エラーや通信障害で食材の入出庫が阻害されない堅牢さを担保（AIが使えない時は即座に手動入庫モードへフォールバック）。
6. **手間を増やす運用は避ける**
   - デフォルトで「それなりに動く」設定を用意し、例外処理は必要な時だけ後から直せる形にする。

## 🛠️ コア機能とUXの工夫

### 1. レシート撮影 ＆ 手動フォールバックで「確実な入庫」
スマホでレシートを撮影すると、GAS経由で **Gemini API** に画像が渡され、購入品目・数量・店名・合計金額などを自動解析。
つまり、なにを買ったかはAIが判断してくれます。

- **AI＋別名テーブルのハイブリッド名寄せ**：
  過去に人間が確認した表記（例：「ﾌﾞﾀｺﾏ」➔「豚肉」）は別名テーブルで即時判定（確信度100%）。未ヒットの品目のみGeminiが判定します。
- **UIでのフィードバック**：
  確信度が高い行は折りたたんでおき、確認が必要な行（新規品目や低確信度）だけを開いて表示。ユーザーは数タップで入庫を完了できます。

### 2. ワンタップ・楽観的UI更新による「ストレスゼロ出庫」
料理中に「食材を使った記録」を入れるのは至難の業です。そのため出庫画面はとことんシンプルに削ぎ落としました。

- 在庫がある食材だけがカード状に並ぶ動的UI。
- ボタンは**「−1」「−½」「全部」の3つだけ。ワンタップで減算。
- 楽観的UI更新を採用し、タップした瞬間に画面上の数を更新。バックグラウンドで非同期に操作ログをサーバーへ集約送信します。

### 3. 「型」モデルによる緩やかな献立提案
本システムでは緻密なレシピ管理を行いません。「何が揃えば成立するか」だけを定義した「型（テンプレート）」を持っています。

> **例：カレーの型**
> - 必須：カレールー、豚肉|鶏肉|挽肉（どれか1つ）、玉ねぎ、にんじん、じゃがいも
> - 選択：なす、きのこ、トマト

現在の在庫ログから自動計算し、「いま作れる献立」と「あと一歩で作れる献立」を提案。「あと一歩」の献立を選び「これにする」を押すと、足りない材料だけが自動的に買い物補充リストへ追加されます。もちろん家に全くない材料から作るレシピにも対応しています。AIを用いて必要材料を推定、買い物リストに入ります。

### 4. 売り場順に並ぶ自動補充リスト
買い物中に店内を行ったり来たりするタイムロスをなくすため、補充リストは売り場（精肉 ➔ 野菜 ➔ 冷凍食品など）の順に自動ソートされます。

常備品の最低在庫割り込みと、採用した献立の不足材料がシームレスに合流し、「今買うべきもの」が最短ルートでチェックできます。

※私は買い物に行くスーパーを固定しているのでできることです。

## 🏗️ システム構成：コストゼロ・サーバーレス

個人開発において「維持費」と「運用コスト」は重要です。

- **フロントエンド**：HTML / JavaScript / CSS（GASデプロイによるSingle Page Application）
- **バックエンド**：Google Apps Script (GAS)
- **データベース**：Google スプレッドシート（追記型ログ運用）
- **AIエンジン**：Gemini API

コード生成にはclaudeを使用しています。無料枠の上限に何度当たったことか…課金してもいいかも？
