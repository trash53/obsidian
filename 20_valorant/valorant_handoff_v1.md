## 2. これまでに整理した内容

### 2.1 「エイムがいい」の分解
- フリック / トラッキング / リコイルコントロール / ターゲットスイッチ / 再現性・精神面
- 境界が曖昧なものとして**クロスヘアプレースメント**(プリエイム)。CoD経験者の強みになり得る

### 2.2 ゲーム構造の理解
- 5v5ラウンド制。死んだらそのラウンドは観戦。1回の判断ミスが重い
- 「毎秒判断」ではなく**情報が来た瞬間に切り替える**ゲーム
- 味方との距離を保ち**トレード**できる位置にいる(1人で前に出ない)
- サイトが複数ある理由=守りに「全部は守れない」制約を課すため。攻めは守りの人数配置を読んで薄い所へ集中する
- 崩すサイトの判断材料: 情報 / 経済 / 直前の流れ / 残り時間。初心者は決める役でなく**正しい情報を渡す役**でよい
- マップは構造(サイト・入口・中央・ローテーション経路)が共通。ラインナップ丸暗記より「地形把握+スキル範囲の感覚」を優先

### 2.3 ロールとエージェント
- ロール: デュエリスト / イニシエーター / コントローラー / センチネル(スナイパーはロールではなく武器)
- 構成の標準は各ロール1+フレックス。初心者のうちは4ロールが揃っているかだけ見ればよい
- **第一候補: ソーヴァ**(イニシエーター、前方の情報取り)。見た目の好みとも合致
- 2体目候補: スカイ(同じ情報系)、バイパー(コントローラー。エリア思考と相性は良いが最初は難)
- 既知のエージェント: キルジョイ、ジェット、サイファー、スカイ、セージ、ネオン
- スキルは**4分類**(スモーク/フラッシュ/情報/設置・妨害)で覚える。ウルトは後回し
- 情報系は「前の情報(攻めたい先)」と「後ろの情報(裏取り検知)」に分けられる。最初は前の情報側(ソーヴァ等)を選ぶ方針

### 2.4 経済(バイ)
- 基本はフルバイ / エコ / フォースバイ。**チームで足並みを揃える**ことが最優先
- 味方の所持金を見て判断。相手の買い読みは中級以降でよい
- 主武器はヴァンダル(遠距離・頭一発)かファントム(連射安定)の好みで可

### 2.5 学習環境の方針
- アンレートやスイフトプレイで「死んで学ぶ」期間を割り切る
- カスタムゲームでマップを選び1人でスキルの飛び方を確認する(設定はゲーム内で要確認)
- デスマッチは戦術練習でなく、地形学習と撃ち方の練習用
- 大会配信は「触る→見る→触る」の往復で。自分の使うエージェント視点+意図を読む見方が合う

## 3. デバイス・設定の結論

### 優先順位
1. ディスプレイ(144Hz以上) → 2. PC性能(フレームレート) → 3. 感度 → 4. キーマウ本体(今のままでよい)

### 判断フロー
- 今のPCで60fps未満/不安定 → PC側(CPU・メモリ)の見直しが先
- 安定して100fps以上 → 144Hzモニターの価値が大きい
- 60fps止まりなら、モニターだけ替えても効果が薄い
- まず**ゲーム内でFPS表示を出して実測**する

### 感度
- 現在のCoD設定: 800DPI / 感度0.44(たぶん)
- バロラントへ**800DPI・感度0.44で設定 → eDPI 352、約37cm/360**。定番範囲(eDPI 200〜400、25〜50cm/360)内
- ⚠ 以前Claudeが出した「CoDからの換算値」は係数に自信のない概算なので**信頼しない**。換算したいなら感度コンバーターで確認
- 方針: 352から開始し、**1〜2週間固定**。違和感があれば10〜20%単位で調整
- カッティングザパイで持ち上げが気になる場合は、感度を少し上げる(eDPI 380〜400)ほうが先。エイムスタイル変更は最後の手段
- 手首を浮かせる持ち方は負担が出やすい。**痛み・違和感が出たら休憩や持ち方の見直しを最優先**

## 4. 現在の実戦課題(デスマッチ1時間で2〜5キル、射撃場も実施)

### 4.1 判明している問題
1. **プリエイムが合っていない**(特に高さ)
2. **角から出すぎる**
3. **止まる前に撃ち始める**(CoDの「撃ちながらマイクロフリック」の癖)
4. **遠距離で胴撃ちになる**(頭を外すのを恐れて照準を下げる心理+反動制御のしすぎの疑い)
5. 動いている敵(ストレイフ)に当てられない

### 4.2 対処方針
| 課題 | 方針 |
|---|---|
| 止まる前に撃つ | 「照準→停止→撃つ」の順に。逆キーは長押しでなく**軽いタップ**、タップ後に一拍置く。慣れたら間隔を詰める。マイクロフリックは**止まった後の微修正**として残す |
| 角から出すぎ | 歩き(Shift)で1歩ずつ視界を広げる。半歩引く |
| プリエイム | 敵が立つ位置・高さを地形学習で覚える。「頭の少し上」を意識して置く |
| 胴撃ち | 最初から頭の高さに照準を置き、**上下に動かさない**。ヘッドショット率を指標に。ダメージ履歴で「狙った所と当たった所のズレ」を確認 |
| 反動 | バロラントは**最初の1〜2発はほぼ無反動**。初弾で下に引かない。連射が必要な近距離だけ軽く抑える |
| 動く敵 | 追従せず、**ストレイフの切り返しで止まる瞬間**に撃つ。無理な撃ち合いは避けて隠れる |
| 初段で倒せない | 遠距離: 止まって2〜3発に区切る/近距離: 押し切る/不利なら撃つのをやめて隠れる。**動きながら撃たない** |
| 武器選択 | エイムが安定するまではファントムも有力。ヴァンダルは初弾の頭一発が前提 |

### 4.3 検証用の確認実験(未実施)
- 射撃場で**反動を一切考えず、頭に照準を合わせて1発だけ**撃つ → 当たるなら「下げる癖」が原因、外れるなら止まるタイミングやプリエイム高さが原因
- 壁に撃って弾痕を見て、引きすぎていないか確認
- 直近Claudeからの質問(未回答): **連射時と単発時で、胴に当たる割合に差はあるか?**
