## 2. これまでに整理した内容(ゲーム理解)

### 2.1 「エイムがいい」の分解
- フリック / トラッキング / リコイルコントロール / ターゲットスイッチ / 再現性・精神面
- 境界が曖昧なものとして**クロスヘアプレースメント**(プリエイム)。CoD経験者の強みになり得る

### 2.2 ゲーム構造
- 5v5ラウンド制。死んだらそのラウンドは観戦
- 「毎秒判断」ではなく**情報が来た瞬間に切り替える**ゲーム
- 味方との距離を保ち**トレード**できる位置にいる
- 攻めは守りの配置を読んで薄い所へ集中。初心者は決める役でなく**正しい情報を渡す役**でよい
- マップは構造(サイト・入口・中央・ローテ経路)を共通理解。ラインナップ丸暗記より「地形把握+スキル範囲の感覚」を優先

### 2.3 ロールとエージェント
- ロール: デュエリスト / イニシエーター / コントローラー / センチネル
- **第一候補: ソーヴァ**(情報取り)。2体目候補: スカイ、バイパー
- スキルは**4分類**(スモーク/フラッシュ/情報/設置・妨害)で覚える。ウルトは後回し
- ※まだソーヴァは本格的に触っていない。撃ち合いに慣れるまでは好きなエージェントで遊んでもよい

### 2.4 経済(バイ)
- フルバイ / エコ / フォースバイ。**チームで足並みを揃える**ことが最優先
- 主武器はヴァンダル(遠距離・頭一発)かファントム(連射安定)。エイムが安定するまではファントムも有力

## 3. デバイス・設定の現状

### 感度(重要・更新済み)
- **現在: 800DPI × ゲーム内感度 0.23(eDPI 約184)**。以前の0.44から大幅に下げた
- 決め方: 「絶対に行き過ぎない値」から上げていって0.23に到達
- 効果: ピークで変な場所を見てしまう問題が、感度を下げただけで解消した
- cm/360は概算で**約71cm**(0.07°/カウントで計算。換算ツールでの確認を推奨。以前のやり取りで出た「約67cm」は不正確だった)
- 低感度なので腕全体の動きが増える。**手首・肘・肩の痛みや違和感が出たら休憩と持ち方の見直しを最優先**
- 方針: **1〜2週間固定**して、次の3点で評価
  1. 行き過ぎの回数(減るか)
  2. 180度ターンや大きなフリックでの足りなさ・持ち上げ回数
  3. 体の痛み・疲れ
  - 2週間たって大きく振る場面の足りなさが目立てば、そこで10%程度上げる検討
- 感度は「止まった状態で最適な値」を基準に決めた。動きと連動したときの違和感は別途評価項目

### マウスパッド
- 布は沈み込んで抵抗が変わる/金属は滑りすぎて止めにくい、が過去の体感
- 候補の方向性: 薄手(2mm前後)で硬めの布、または表面が均一な硬め系。**低感度なので広めを推奨**
- 変更するなら感度は触らず、パッドだけ変えて1〜2週間評価
- 未回答: 金属パッドは「止めにくかった」か「滑りが気持ちよかった」か

### ディスプレイ
- 144Hz導入後、「動きが良くなった」「当たるようになった」「相手の細かい動きが見える」「ストッピングしながら顔を出す精度が上がった」と実感あり
- 新モニター直後は感覚が良く出やすいので、数日〜1週間後に再確認

## 4. 実戦課題と、判明した原因

### 4.1 確定している原因(録画・射撃場検証で確認)
1. **射撃場の単発では頭に当たる** → エイム精度自体は問題なし
2. デスマッチで胴になるのは**ヘッドライン(照準の高さ)のずれ**。味方の頭を基準に合わせたら入り始めた
3. **ピーク時、左角で照準が右にずれる**。CoD/R6S式の「角に照準を合わせ続けながら動く」やり方が、バロラントの移動速度では通用しにくい。**照準を先に置く → 歩きで出る** が対処
4. **感度が高すぎて行き過ぎ** → 0.23へ変更し改善傾向
5. **ストッピングできていない**: 止まり切る前に撃つ/撃ちながら動いている
6. **逆キーのカウンターストレイフは、押す時間が長すぎて逆方向に動き出すため当面やめる**。キーを離して止まるのを待つ
7. **意味のない場所(壁など)を見る時間が長い**。クリアリング・カッティングパイの順序が悪く、フリック距離が伸びる
8. **別方向から撃たれると焦って「引き撃ち」する**(CoD/R6Sの癖)。バロラントでは動きながらだと弾が散るので「撃っていない」のとほぼ同じ
9. 半身ピークの相手は置きエイムで取れるが、**オーバーピークには崩れやすい**

### 4.2 現在の型(行動ルール)
- **歩きで出る → キーを離す → 止まったのを確認 → 撃つ**
- 角の手前で、**先に頭の高さ・敵が立つ位置へ照準を置いてから**体を出す(移動と照準を分ける)
- 焦ったときの選択肢は**2つだけ**: 「引く(撃たずに隠れる)」か「止まって撃つ」。**引き撃ちは選択肢から外す**。迷ったら引く
- 動く敵は追従せず、**止まる瞬間を待って撃つ**
- バロラントでは右クリック(覗き)は使わず**腰撃ちに一本化**。CoDのADSの代わりに「止まる」を構えの合図にする
- 歩き(Shift)は精度が落ちにくいので、止まり切る前に撃ってしまう癖への保険になる(武器ごとの精度は射撃場の弾痕で確認)

### 4.3 学習環境
- ボット系モードは**射撃場のみ**(カスタムゲームで動くボットは使えない様子)。ゲーム内で確認した結果を優先
- 射撃場: 止まって頭に単発、歩きで出て止まって単発、弾痕確認など
- デスマッチ: **1試合1テーマ**。キル数は気にしない
- 録画での振り返りは週1〜2回。見るのは「撃った瞬間に動いていたか」「どちらが先に見えたか」「照準が頭からどれくらいずれていたか」
